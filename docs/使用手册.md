# 📦 Health Float 使用手册

> 大水时代，大睡时代，大眺望时代，大健康时代。

---

## 一、这是什么

一个**永远置顶**的桌面小舷窗。它会在该的时候提醒你：

| 提醒 | 默认频率 |
|------|---------|
| 👀 看远方 20 秒（护眼） | 每 20 分钟 |
| 🧘 站起来动一动 | 每 1 小时 |
| 💧 喝杯水 | 每 2 小时 |
| 🛁 去洗澡 | 每天 21:30 |
| 🌙 早点睡觉 | 每天 22:30 |

所有时间都读你电脑的本地时钟，**换电脑、换时区都不用重新设置**。

## 二、怎么打开

### macOS

1. 双击下载到的 `Health.Float.dmg`
2. 把 `Health Float.app` 拖进「应用程序」文件夹
3. 双击 `Health Float.app`
4. 第一次会弹出**设置窗口**：用**上下箭头**拨动，选好洗澡和睡觉时间 → 点「保存 ✓」
5. 一个浅蓝色小舷窗出现在屏幕**右下角**，开始工作

> **提示**：如果 macOS 说"无法验证开发者"，去「系统设置 → 隐私与安全性」点「仍要打开」。

### Windows

1. 解压 `HealthFloat-Windows.zip`
2. 双击 `Health Float.exe`
3. 首次会弹出设置窗口，选好时间保存
4. 小舷窗出现在右下角

> **不需要装 Python** —— 下载的 exe 已经自带运行环境。
> 如果双击没反应，先看「五、常见问题」里的防火墙提示。

### Linux

1. 终端执行一次：`chmod +x Health.Float.AppImage`
2. 双击运行

> 如果双击打不开，右键 → 「属性」→ 勾选「允许作为程序执行」。

## 三、它到底在屏幕哪儿？

打开后，屏幕上会出现一个**浅蓝色的小舷窗**，默认在**屏幕右下角**。

- 舷窗里的图标 = **下一个要来的提醒**（💧 快到喝水就显示喝水，🌙 快到睡觉就显示睡觉）
- 舷窗下方的灰条 = 倒计时 + 提醒名称
- 右下角有个 **⚙ 齿轮** —— 点它打开设置

**拖动**：按住舷窗可以拖到屏幕任意角落，位置会被记住。

**它不会自己消失**——除非你退出它。想让它开机就有，见第五节。

## 四、怎么设置（重点）

**打开设置的方式（三种，任选）：**

- 🅰 **点舷窗右下角的 ⚙ 齿轮** ← 最推荐，看得见
- 🅱 双击舷窗
- 🅲 右键舷窗 → 「⚙ 打开设置…」

### 设置项说明

| 项目 | 怎么改 | 说明 |
|------|--------|------|
| 看远方 🪟 | 拨轮改分钟数 | 填 `0` = 关闭这项提醒 |
| 起来动一动 🧘 | 拨轮改分钟数 | 填 `0` = 关闭 |
| 喝水 💧 | 拨轮改分钟数 | 填 `0` = 关闭 |
| 洗澡提醒 🛁 | 拨小时 + 分钟 | 留空 = 不提醒 |
| 睡觉提醒 🌙 | 拨小时 + 分钟 | 留空 = 不提醒 |
| 提前预告 ⏰ | 拨秒数 | 快到点时提前多久开始"呼吸"提醒 |
| 洗澡/睡觉黑屏 🖥 | 拨秒数 | 提醒前全屏黑几秒，`0` = 不黑屏 |
| 眺望/站立黑屏 🌑 | 拨秒数 | 同上 |
| 会议模式 🎙 | 勾选框 | 开启后**永不黑屏**（开会投屏用） |
| 提示音 🔔 | 勾选框 | 关掉 = **静音模式**（只弹窗不出声） |

**保存立即生效**，不需要重启。

### 快捷开关

**右键舷窗**打开的菜单里有：

- ⚙ 打开设置…
- 🎙 会议模式：开 / 关 — 开会前一键切换，提醒照弹但绝不全屏黑屏
- 🔕 静音模式：开 / 关 — 只弹窗不出声，适合图书馆 / 共享空间
- ✕ 退出

## 五、几个贴心细节

**🌑 黑屏提醒**

- 看远方 / 起来活动前 → 全屏黑 **2 秒**
- 洗澡 / 睡觉前 → 全屏黑 **10 秒**
- 黑屏期间**你还在动鼠标** → 它就继续黑着，直到你真的停下来
- **点一下随时跳过**（最多延长 30 次，不会把你永久锁在黑屏里）
- 黑屏**不会抢键盘焦点**——你正在打的字不会丢

**💤 不会半夜轰炸**

合盖睡了一夜？醒来**不会**被一堆过期提醒连环轰炸。系统检测到休眠超过 5 分钟，会把错过的时间点静默重排到未来。

**🔕 静音模式**

提醒照常弹，但完全不出声。

## 六、常见问题

**Q：Windows 双击没反应 / 被防火墙拦？**

打包的 exe 第一次运行可能触发 Windows Defender 的「已阻止」提示：

1. 弹出蓝窗时点「更多信息」→「仍要运行」
2. 或去「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」，把被拦的项设为允许

**Q：找不到设置入口？**
点舷窗**右下角的 ⚙ 齿轮**，或右键舷窗。齿轮一直在，不会消失。

**Q：想临时关掉所有黑屏？**
右键 → 会议模式。

**Q：能拖到别的地方吗？**
可以，拖住舷窗挪到屏幕任意角落。

**Q：怎么让它开机自动运行？**

- macOS：系统设置 → 通用 → 登录项 → `+` → 选 Health Float.app
- Windows：`Win + R` → 输入 `shell:startup` → 把 Health Float.exe 的快捷方式拖进去

**Q：配置存在哪？**

- macOS：`~/Library/Application Support/HealthFloat/config.json`
- Windows：`%APPDATA%\HealthFloat\config.json`
- Linux：`~/.config/health-float/config.json`

放在用户目录，所以重装、升级、换电脑都不会丢。

**Q：完全退出？**
右键舷窗 → ✕ 退出。
